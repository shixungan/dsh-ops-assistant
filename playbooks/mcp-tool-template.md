# IP 路径查询

## 工具
YOUR_TRACE_TOOL

## 描述
查询两个 IP 之间的转发路径。将工具标识替换成 DSH 发现列表中的实际名称，并读取真实参数结构。

## 数据对象
该 MCP 管理的路由或路径数据，需核对数据来源和更新周期。

## 输入
下方 source_ip、destination_ip、max_hops 只是字段名示例，需根据实际参数修改。源/目的 IP 从所选告警获取，不混用交换机管理 IP。

## 输出
填写节点、接口、VRF、标签和路径状态等实际返回字段的含义；不要求采用 Neo4j 输出结构。

## 关联关系
核对返回端点与本条告警是否一致，结合本窗口观测验证关联假设。

## 时间口径
确认是当前、历史还是计算得到的候选路径；不能直接推断历史窗口内实际转发情况。

## 限制
查询失败或没有路径不等于链路正常。不能确认路径变化时间时保留不确定性。

## 调用参数
```json
{
  "source_ip": "{{alert.srcip}}",
  "destination_ip": "{{alert.dstip}}",
  "max_hops": 8
}
```
